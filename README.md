# PharmaGuard

An agentic AI research project for pharmacovigilance
and adverse drug event case investigation.

## Objectives

- Extract structured information from adverse-event reports.
- Validate case completeness and identify missing information.
- Detect potential duplicate reports.
- Retrieve drug safety evidence with source citations.
- Coordinate case investigation workflows with human review.

## Tech Stack

- Python
- FastAPI
- Pydantic
- LangGraph
- openFDA API

## Project Status

Phase 1: Environment setup and API foundation.

## Safety Notice

This is a research prototype, not a medical
decision-making system or a regulatory submission tool.
